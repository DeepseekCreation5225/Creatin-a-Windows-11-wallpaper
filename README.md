# 🎨 Perfect Background Studio

A modern, feature-rich Python application designed to customize your Steam interface and tweak Windows 11 settings. Built with `CustomTkinter` for a sleek, dark-themed UI with smooth animations.

## ✨ Features

* 🖼️ **Custom Steam Background:** Set any image as your Steam background across the Store, Library, Community, and Profile pages.
* ⚙️ **Steam UI Customizer:** Adjust the opacity, blur, and darkness of the Steam interface to make your background look perfect.
* 🧹 **Steam Cleaner:** Hide unwanted elements like the Friends List or "What's New" banners using built-in CSS toggles or your own custom CSS code.
* 🪟 **Windows 11 Tweaks:** Change desktop wallpapers directly from the app and switch the Start menu alignment (Left/Center).
* 🎞️ **Slideshow Mode:** Automatically rotate your Steam background from a selected folder at custom intervals.
* 📚 **Presets & History:** Save your favorite combinations as presets and easily switch between your recently used backgrounds.
* ⌨️ **Global Hotkeys:** Control your background from anywhere using customizable keyboard shortcuts (e.g., `Ctrl+Alt+B`).
* 🌍 **Multi-Language Support:** Fully translated in both English and Russian.
* 🚀 **Auto-Updater & Bootloader:** Creates its own system files on the first run, requests Administrator privileges, and automatically updates older versions.
* 💻 **Auto-Install Dependencies:** If you are missing required Python libraries, the program will offer to install them automatically.
